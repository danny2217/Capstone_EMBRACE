=====================================================================
 Air-Rhythm  —  호흡 인장 센서 측정 및 실시간 시각화
=====================================================================
 범위: 호흡 데이터 수집 + 실시간 그래프 + 보고서용 이미지 저장
       (과호흡 판단 등 검출 기능은 추후 확장)

---------------------------------------------------------------------
1. 하드웨어 연결 (외부 저항 없음, ESP32 내부 풀업 사용)
---------------------------------------------------------------------

    3.3V ──[ 내부 풀업 약 45kΩ ]──┬── GPIO32
                                   │
                          [ 고무줄 인장 센서 ]
                                   │
                                  GND

  ESP32-WROOM-32 핀      연결
  ------------------    ---------------------------
  GPIO32 (ADC1_CH4)     인장 센서 한쪽 끝
  GND                   인장 센서 다른 쪽 끝
  3.3V                  연결하지 않음 (풀업이 내부에서 3.3V 를 공급)

  ※ 반드시 GPIO32 또는 GPIO33 을 사용할 것
     - GPIO34~39 : 내부 풀업 회로가 없음 → 값이 무작위로 흔들림
     - ADC2 핀(GPIO4, 12~15, 25~27 등) : BLE/WiFi 사용 시 읽기 실패
  ※ 센서-전선 접합부는 절연 테이프로 고정. 접합부가 흔들리면 그 자체가
     접촉 저항 노이즈원이 된다.

---------------------------------------------------------------------
2. 펌웨어 업로드 (Arduino IDE)
---------------------------------------------------------------------
  1) 보드 매니저에서 "esp32 by Espressif Systems" 설치 (2.x / 3.x 모두 지원)
  2) 보드: "ESP32 Dev Module"
  3) firmware/sensor_reader/sensor_reader.ino 열고 업로드
     - 같은 폴더의 sensor_app.cpp / sensor_app.h 가 탭으로 함께 열려야 정상
     - 설정값(핀 번호, 필터 길이 등)은 sensor_app.cpp 상단 cfg 에서 수정
  4) 시리얼 모니터 115200 bps 에서 확인:
        # AirRhythm sensor_reader v1.0 ... pin=GPIO32 pullup=internal fs=50Hz ...
        # pullup_register=ON core=x.y.z     ← 반드시 ON 이어야 함
        0   1234   1532   1530              ← seq  t_ms  mv  ma_mv
  5) 확인 후 시리얼 모니터를 "닫는다" (열려 있으면 파이썬이 포트를 못 연다)

  출력 형식 (TAB 구분)
    seq    일련번호 (호스트가 유실 샘플 계산)
    t_ms   기기 시각 ms (그래프 시간축)
    mv     오버샘플링(8회) 평균 전압, eFuse 보정 mV
    ma_mv  이동 평균(10샘플 = 0.2 s) 출력
  '#' 으로 시작하는 줄 = 진단/경고
    # fs=50.00Hz ...           1초마다 실측 표본화 주파수
    # WARN sensor_open ...     0.5 s 이상 3000 mV 이상 (센서 분리/단선)
    # WARN sensor_short ...    0.5 s 이상 60 mV 이하 (단락)

---------------------------------------------------------------------
3. 파이썬 실행 (Windows, Python 3.9+)
---------------------------------------------------------------------
  cd software
  pip install -r requirements.txt

  python visualizer.py --list                포트 확인 (예: COM5)
  python visualizer.py --port COM5           실시간 그래프 + CSV 자동 기록
  python visualizer.py --demo                보드 없이 모의 신호로 화면 점검

  실시간 창 단축키
    s  현재 화면 PNG 저장 → report_images/
    p  일시정지/재개 (정지 중에도 수신·CSV 기록은 계속)
    q  종료 (마지막 화면 자동 저장 + CSV 경로 출력)
    1~5  측정 구간 표시 → CSV 의 phase 열에 기록 (분석 모드가 사용)
         1 정지(안정화)  2 심호흡  3 평상 호흡  4 숨 참기  5 움직임  0 해제
    ※ 키가 안 먹으면 그래프 창을 한 번 클릭해 포커스를 준다

  화면 상단 상태줄
    수신 Hz   : PC 가 실제로 받은 속도
    기기 fs   : ESP32 가 보고한 표본화 속도
    유실      : seq 번호 건너뜀 개수 (0 이어야 정상)

  보고서용 그래프 (저장된 CSV 에서 구간 지정)
    python visualizer.py --replay ../data/breath_YYYYMMDD_HHMMSS.csv --start 10 --duration 30
    python visualizer.py --replay ../data/breath_....csv --no-show      (창 없이 PNG 만)
  → 실시간 캡처보다 재현 가능하고 구간이 명확해 보고서에 권장.
     phase 열이 있으면 구간별 배경색이 칠해진다.

  정량 분석 (TC-03 근거: 동작점·포화·진폭·노이즈·SNR·호흡수 + 판정)
    python visualizer.py --analyze ../data/breath_....csv --count 15 --no-show
      --count : 평상 호흡 구간 동안 관찰자가 직접 센 호흡 횟수 (검출값과 비교)
    → report_images/ 에 *_analysis.png (파형+스펙트럼), *_analysis.txt (수치표)
    SNR 은 '평상 호흡(3)' 과 '숨 참기(4)' 구간이 모두 표시되어 있어야 계산된다.

  --invert : y축 반전. 늘리면 전압이 내려가는 센서일 때 '들숨 = 위' 로 보이게
             (실시간/replay/analyze 공통, 데이터 값은 바꾸지 않음)

  CSV 열: host_time, seq, t_ms, elapsed_s, mv, ma_mv, phase   (data/ 폴더)

4. 테스트 시나리오
---------------------------------------------------------------------
  TC-01  업로드 후 시리얼 모니터
         - pullup_register=ON 확인
         - 센서를 GPIO32 에서 뽑으면 약 3000 mV 이상 + WARN sensor_open
           (풀업이 꺼져 있다면 값이 무작위로 흔들린다 → 풀업 동작 증거)
         - 센서 연결 후 늘렸을 때 mv 가 변함
  TC-02  visualizer.py --port COMx → 파형 표시, 유실 0, 수신 Hz ≈ 50
  TC-03  아래 '측정 프로토콜' 수행 → --analyze 판정표로 확인
  TC-04  's' 키 또는 --replay 로 report_images/ 에 PNG 생성 확인

  측정 프로토콜 (1회 약 2분, 조작자가 숫자 키로 구간 표시)
    키 1  정지(안정화) 10 s  착용 후 앉아서 가만히, 자연 호흡
    키 2  심호흡 3회         천천히 최대한 깊게
    키 3  평상 호흡 60 s     관찰자는 호흡 횟수를 직접 센다 (--count 에 입력)
    키 4  숨 참기 10 s       들이쉰 상태로 정지 → 노이즈 기준
    키 5  움직임 10 s        팔 들기·몸 비틀기·말하기 (아티팩트 크기 확인)
    키 0  해제 → q 로 종료

  잠정 판정 기준 (visualizer.py 의 OP_RANGE_MV / SNR_GOOD_DB 에서 변경)
    유실 0 · 포화 < 0.1 % · 동작점 500–2600 mV · SNR ≥ 20 dB · 호흡 횟수 ±1

5. 풀업 저항 결정 (센서 교체 시마다 확인)
---------------------------------------------------------------------
  멀티미터로 센서 저항 측정 — 반드시 보드에서 분리한 상태로
    Ra = 착용 상태(평상 장력)   Rb = 최대 들숨 상태

  V = 3.3 V × Rs / (Rs + Rpu),   ADC 선형 범위 약 150–3100 mV
  ΔV 가 최대가 되는 풀업 값:  Rpu ≈ √(Ra × Rb)

    √(Ra·Rb) 이  약 15 kΩ ~ 150 kΩ  → 내부 풀업 유지 (변경 없음)
                  150 kΩ 초과         → 외부 풀업 (3V3 ─[R]─ D32), R ≈ √(Ra·Rb)
                                         또는 클립 간격 단축으로 Rs 자체를 낮춤
                  15 kΩ 미만          → 외부 풀업, R ≈ √(Ra·Rb) (내부 풀업은 너무 커서
                                         전압이 ADC 하한 근처로 붙고 변화폭이 작음)
  외부 풀업 사용 시 sensor_app.cpp 의 cfg::USE_INTERNAL_PULLUP = false 후 재업로드
  (명세서 '외부 저항 부착 ❌' 항목도 함께 수정해야 함)

6. 문제 해결
---------------------------------------------------------------------
  포트 열기 실패        시리얼 모니터/플로터 닫기, USB 케이블이 데이터용인지,
                        CP210x/CH340 드라이버 설치 확인
  pullup_register=OFF   핀 번호 확인 (34~39 사용 여부), 코드에서 setup 이후
                        analogSetAttenuation 등을 추가로 호출하지 않았는지 확인
  값이 거의 0 근처      센서 저항이 풀업 대비 너무 작음 → 멀티미터로 센서 저항 측정
  값이 3000 mV 근처 고정 센서 단선 또는 저항이 너무 큼
  그래프 한글이 □□     Windows 는 맑은 고딕 자동 사용. 다른 OS 는 나눔고딕 설치
