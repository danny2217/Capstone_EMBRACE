## 3. 코드 구조 (Air-Rhythm.zip)
```
firmware/sensor_reader/
  sensor_reader.ino   setup/loop 만 (Arduino 자동 prototype 문제 회피용으로 분리)
  sensor_app.h/.cpp   실제 구현. 50 Hz FreeRTOS 태스크(vTaskDelayUntil), ADC 8회 오버샘플,
                      이동평균 10샘플, 단선/단락 판정, 풀업 레지스터 직접 확인,
                      cfg::USE_INTERNAL_PULLUP 스위치(외부 풀업 전환용), 비-ESP32 보드면 #error
software/visualizer.py  --port COMx 실시간 그래프+CSV / --demo / --replay CSV → PNG / --list
                        수신 데이터로 ADC 포화(≥3000 mV)·단락 경고 표시
software/requirements.txt, README.txt
data/DEMO_simulated_breath.csv          모의 데이터 (실측 아님)
report_images/DEMO_*.png                모의 데이터 그래프 (실측 아님)
```
시리얼 출력: `seq<TAB>t_ms<TAB>mv<TAB>ma_mv`, `#` 줄 = 진단 (`# fs=...`, `# WARN ...`, `# pullup_register=ON/OFF`)

## 4-1. 2026-10-13 변경 (visualizer.py)
- 인장 센서 교체 완료(사용자 보고). 저항값(이완/인장)은 아직 미기록 → README 5절 기준으로 풀업 결정.
- 실시간 창 숫자 키 1~5 로 측정 구간 표시 → CSV `phase` 열 (구 CSV 도 replay/analyze 호환)
- `--analyze CSV [--count N]`: 동작점·포화·진폭(P5–95)·노이즈 σ(숨 참기)·SNR·호흡수(스펙트럼+사이클) + 잠정 판정. 합성 데이터로 검증(15 bpm, 진폭 79 mV 재현)
- `--invert`: y축 반전 (늘리면 전압이 내려가는 센서용)
- 버그 수정: 's'/'p' 가 matplotlib 기본 단축키(저장 대화상자 / pan)와 충돌 → 기본 바인딩 제거
- 버그 수정: --demo 신호의 호흡수가 위상 계산 오류로 크게 흔들리던 문제 (기존 DEMO_*.csv/png 는 구버전 생성물)

## 5. 현재 문제 (우선순위 순)
1. **센서 파손**: 손으로 늘려보다 고무줄이 끊어짐 → 교체 센서 필요. 최대 신장률·내구성을 사양으로 기록할 것 (아동용 조끼 안전 요구사항과 직결).
2. **동작점 포화**: 센서를 연결해도 3145 mV(ADC 상한)에 붙어 호흡에 반응 없음. 손으로 세게 당겨야만 움직임.
   - 추정 원인: 센서 저항 ≫ 내부 풀업(약 45 kΩ, 칩마다 30~80 kΩ) → V = 3.3·Rs/(Rs+Rpu) 가 상한 초과. 또는 접촉 불량.
   - 소프트웨어 증폭으로는 해결 불가 (잘린 신호).
   - 미결정 선택지: **A** 측정 구간(클립 간격) 5~10 cm로 단축 / **B** 외부 풀업 저항 R≈Rs (`USE_INTERNAL_PULLUP=false`, 명세서 수정 필요, 교수 권고안) / **C** 미리 당겨 감기(늘리면 저항이 줄어드는 센서일 때만).
3. **저항 변화 방향 미확인**: 당겼을 때 mV가 상한에서 내려온 것으로 보임 → 늘리면 저항이 줄어드는 센서일 가능성. 확인 필요.
4. 명세서 정리 필요: "외부 저항(예: 10옴)" 오기(10 kΩ?), 제목은 BLE인데 범위는 시리얼.
