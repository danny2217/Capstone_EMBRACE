# grip-sensor — 가방끈 악력 (ZD10-100 × 2)

가방끈 좌/우에 ZD10-100(FSR)을 하나씩 넣어 아동이 끈을 쥐는지, 얼마나 세게(상대값), 얼마나 오래 쥐는지를 잰다.
펌웨어는 루트 `firmware/embrace_node/` 의 `grip_l`(GPIO5), `grip_r`(GPIO6) 열이다.

> **지표는 "몇 kgf" 가 아니다.** ZD10-100 은 정격 500 g 이라 세게 쥐면 값이 평평해진다(포화).
> 그래서 착용자별 기준선·최대 쥠으로 정규화한 **쥠 지수(0~1)** 와 **쥠 구간(시작·끝·지속 시간)** 을 쓴다.

## 회로

`3V3 ─[ZD10-100 ∥ R_bias 150 kΩ]─ GPIO5/6 ─[R_ref 10 kΩ]─ GND`, 노드에 100 nF. 무부하 기준 약 206 mV.
센서는 웨빙 한 겹 안쪽에 넣어 손과 직접 닿지 않게 한다. 자세한 그림은 `docs/wiring.md`.

## 실행 (저장소 루트에서 `pip install -r requirements.txt` 한 번)

```bash
cd grip-sensor/software
python visualizer.py --port COM5      # 처음 3초는 손을 떼고 기다린다 → 기준선
python visualizer.py --demo           # 보드 없이 모의 데이터
python visualizer.py --replay ../data/grip_YYYYMMDD_HHMMSS.csv --no-show   # PNG + 통계 (TC-G1, TC-G2)
```

실시간 단축키: `b` 기준선(앞 2초 평균) · `m` 최대 쥠(앞 3초 최대값, `data/grip_calib.json` 저장) · `s` PNG · `p` 일시정지 · `q` 종료

## 처리 방법 (`GripAnalyzer`, 실시간·재생 공통)

| 단계 | 내용 |
|---|---|
| 기준선 | 시작 후 3초 값의 **하위 10%** (측정 중 잠깐 쥐어도 끌려 올라가지 않음). 쥐지 않은 동안 아래쪽으로만 따라감 |
| 쥠 지수 | (현재 − 기준선) / (최대 쥠 − 기준선), 0~1 로 자름. 최대 쥠은 `m` 보정값, 없으면 지금까지의 최고값 |
| 쥠 구간 | 지수 0.30 이상에서 시작, 0.15 이하에서 끝 (히스테리시스), 0.2 s 미만은 버림 |
| 센서 이상 | 펌웨어 flags 가 단선/단락이면 그 구간은 판정하지 않음 |

※ 쥠 구간은 관찰·보고서용 표시이지 **전조 검출 알고리즘이 아니다.** TC-G2(걷기·끈 만지작) 데이터로 오검출 문턱 근거를 모은 뒤 설계한다.
※ `m` 보정 없이 지수를 쓰면, 한 번 세게 쥔 뒤의 보통 쥠이 작게 보인다 (최대값이 커지므로). 측정 전에 반드시 `m` 보정을 한다.
