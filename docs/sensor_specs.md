# 센서 사양 · 실측 기록

## ZD10-100 (저항식 박막 압력센서, FSR) — 악력 2개 + 압박 2개

| 사양 (판매처) | 값 | 설계 영향 |
|---|---|---|
| 측정 범위 | 0~500 g | 악력은 포화 가능 → 지표는 "쥠 여부·상대 강도·지속 시간" |
| 무부하 저항 | 10 MΩ 초과 | 무부하 ≈ 0 V = 단선과 구분 불가 → R_bias 필수 |
| 반복성 | ±5% (50% 하중) | 같은 센서 반복 오차 한계 |
| 일관성 (개체 간) | ±15% | 4개 모두 **개별 보정** |
| 이력 | +10% | 가압 중/배기 중 같은 압력이라도 값이 다름 |
| 응답 하한 | 20 g 미만 | 압박(감지부 단독, Ø10 mm 가정) 20 mmHg ≈ 21 g 과 겹침 |
| 응답 시간 | 10 ms 미만 | 50 Hz 충분 |
| 작동 전압 | 3.3 V | ESP32-S3 3V3 로 직접 |
| 감지부 지름 | **미확인 — 실측** | 압력 환산의 분모 |

출처: 판매처 사양 이미지, [Probots ZD10-100](https://probots.co.in/0-500g-flex-sensor-resistive-film-pressure-sensor-zd10-100.html)
