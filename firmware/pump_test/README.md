# 펌프·밸브 단독 시험 스케치 (동료 코드, air_pump 브랜치에서 가져옴)

| 폴더 | 원본 커밋 | 핀 (L298N IN1~IN4) | 상태 |
|---|---|---|---|
| `Air_pump_valve/` | 2aaa189 (11/10) | 15, 16, 17, 18 | **통합 펌웨어의 기준** (`src/pneumatic.cpp` 로 이식) |
| `Air_pump_valve_test/` | ef023f3 (11/5) | 4, 5, 6, 7 | ⚠ 센서 핀(호흡 4, 악력 5·6, 가슴 7)과 겹침 — 센서를 꽂은 보드에 올리지 말 것 |

- Arduino IDE 는 폴더 이름과 `.ino` 이름이 같아야 열린다. 그래서 스케치마다 폴더를 따로 두었다.
- 두 스케치 모두 `delay()` 로 3~5 s 가압과 배기를 반복한다. **펌프·배선 점검용**이다. 조끼를 입은 상태에서는 쓰지 않는다.
- 실제 동작은 `firmware/embrace_node` (상태 머신, 안전 감시 포함)로 한다. 설명은 `docs/control_fsm.md`.
